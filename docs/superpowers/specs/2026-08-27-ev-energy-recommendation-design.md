# EV 에너지 소비 예측 및 운행 추천 설계

## 목적

특정 단일 차종을 대상으로, 출발지·도착지·출발 시각에서 얻는 거리와
외기 온도를 바탕으로 전기차의 에너지 소비율을 예측한다. 그 예측을 사용해
속도, HVAC 출력, 운전 성향 지수, 타이어 공기압 후보를 비교하고, 사용자가
선택한 시간 우선순위 안에서 에너지 사용량이 가장 적은 운행 계획을 추천한다.

초기 범위는 `datas_ml/ev_energy_consumption.csv`를 이용한 소비율 예측 및
추천 규칙 검증이다. 지도와 날씨 API의 실제 연동은 이후 단계에서 모델 입력을
주입하는 기능으로 추가한다.

## 사용자 입력과 외부 데이터

사용자는 출발지, 도착지, 출발 시각 및 추천 모드만 선택한다.

- 지도 API: 경로 거리와 기준 예상 소요 시간
- 날씨 API: 출발 시각의 외기 온도
- 차량 프로필: HVAC, 운전 성향, 타이어 공기압의 기본값
- 초기 가정: 적재량과 배터리 온도는 대표값으로 고정

경사도는 초기 모델에서 제외한다. 지도 고도만으로는 실제 운행의 경사 순서,
회생제동 및 교통 상황까지 반영한 신뢰도 높은 값을 얻기 어렵기 때문이다.

## 데이터와 변수

목표값은 `energy_consumption_kwhper100km`이며 단위는 kWh/100km이다.

초기 서비스 모델의 후보 입력은 다음과 같다.

| 역할 | 열 |
| --- | --- |
| 자동 주입 | `ambient_temp_C`, `trip_distance_km` |
| 추천 후보 | `speed_kmh`, `hvac_power_kw`, `driving_style_index`, `tire_pressure_bar` |
| 고정 기본값 | `payload_kg`, `battery_temp_C` |
| 제외 | `road_grade_pct` |

두 모델을 비교한다. 기본 모델은 `payload_kg`와 `battery_temp_C`를 제외해
실제 서비스 입력과의 일치를 우선한다. 확장 모델은 두 열을 포함해 센서 또는
프로필 정보가 있을 때의 개선 폭을 확인한다. 기본 모델과의 성능 차이가 작으면
기본 모델을 선택한다.

## 단계별 분석

1. **품질 점검**: 행·열 수, 자료형, 결측치, 중복, 기술 통계와 변수별 범위를
   확인한다. 이상치 후보는 먼저 표시하고 데이터 오류가 확인되기 전에는 제거하지
   않는다.
2. **단변량 시각화**: 목표 소비율의 히스토그램과 박스플롯, 모든 후보 입력의
   히스토그램, 결측치 막대그래프 또는 행렬을 만든다. 관측 범위 밖의 추천을
   제한할 근거를 기록한다.
3. **관계와 상호작용 시각화**: 속도·온도·HVAC와 소비율의 산점도 및 추세선을
   만들고, 운전 성향과 공기압은 구간별 박스플롯을 만든다. 속도 구간과 온도
   구간별 평균 소비율·표본 수 히트맵으로 상호작용을 본다. 상관계수는 보조
   자료이며 인과관계 근거로 사용하지 않는다.
4. **학습과 검증**: 데이터를 훈련 70%, 검증 15%, 테스트 15%로 무작위 분리하고
   난수 시드를 고정한다. 평균 소비율만 예측하는 기준선과 비교한다. 주 지표는
   MAE, 보조 지표는 RMSE와 R²다.

## 성공 기준과 불확실성

테스트 MAE의 초기 목표는 `1.5 kWh/100km 이하`다. RMSE로 큰 오차 조건도
점검한다. 총소비량 오차의 근사치는 다음과 같다.

`총소비량 오차 ≈ MAE × 거리(km) / 100`

추천 절감량이 이 불확실성에 비해 충분히 크지 않으면 강한 절감 추천 대신
"예측 오차 범위 안의 차이"로 표시한다.

## 추천 알고리즘

1. 지도 API의 기준 소요 시간으로 기준 평균 속도를 구하고, 차량 프로필의
   기본값과 함께 현재 운행 계획을 구성한다.
2. 속도, HVAC, 운전 성향, 공기압의 후보 조합을 생성한다. 모든 후보는 학습
   데이터에서 충분히 관측된 범위 안에 있어야 하며, 공기압은 제조사 허용 범위를
   벗어나지 않는다.
3. 후보마다 소비율을 예측하고 총소비량과 예상 소요 시간을 계산한다.
4. 선택한 추천 모드의 시간 제약을 만족하는 후보 가운데 총소비량이 가장 작은
   계획을 선택한다.

`예상 총소비량 = 예상 소비율 × 거리 / 100`

`예상 소요 시간 = 거리 / 후보 평균 속도`

추천 모드의 초기 제약은 다음과 같다.

| 모드 | 시간 제약 |
| --- | --- |
| 빠르게 | 기준 시간에 최대한 가깝게 유지 |
| 균형 | 기준 시간보다 최대 10% 또는 10분 증가 |
| 절약 우선 | 기준 시간보다 최대 20% 증가 |

## 범위와 후속 확장

초기 단계에서는 실제 지도·날씨 API 호출, 다차종 일반화, 경사도 반영, 실시간
교통 보정 및 강화학습을 구현하지 않는다. 이후 API 연동으로 거리·시간·온도를
모델 입력에 주입하고, 차량별 데이터가 추가되면 차종 특성까지 포함한 확장 모델을
검토한다.

- 기준선·기본 모델·확장 모델의 테스트 지표 비교
- 대표 시나리오별 현재 계획, 추천 계획, 절감량, 시간 증가 및 불확실성 표시
